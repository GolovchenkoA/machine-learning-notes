# Learning ML and NLP basics (LinkedIn Learning)

> Not checked against the live catalog: ratings, durations and availability may differ. The first five titles were confirmed to exist; the last three (marked *from memory*) should be searched by name.

## ML fundamentals

- [ ] **[Machine Learning with Python: Foundations](https://www.linkedin.com/learning/machine-learning-with-python-foundations)** (Frederick Nwanganga). Start here. Hands-on scikit-learn: data prep, training, evaluation, tuning. Good for an engineer who wants code over theory.
- [ ] **Artificial Intelligence Foundations: Machine Learning** (Kesha Williams, beginner, ~1h 50m). Short conceptual overview of classification, regression and model evaluation. Skip if you already know the basics.
- [ ] **Deep Learning: Getting Started** (Jonathan Fernandes, *from memory*). Follow-up once the basics are solid.
- [ ] **Artificial Intelligence Foundations: Neural Networks** (Jonathan Fernandes, *from memory*). Follow-up once the basics are solid.

## NLP

- [ ] **[NLP with Python for Machine Learning Essential Training](https://lynda.com/Python-tutorials/NLP-Python-Machine-Learning-Essential-Training/622075-2.html)** (Derek Jedamski). Best NLP starting point: cleaning, tokenization, vectorization (TF-IDF), building classifiers.
- [ ] **Introduction to Large Language Models** (Jonathan Fernandes, intermediate, ~1h 17m). Short conceptual intro to how LLMs work.
- [ ] **Transformers: Text Classification for NLP Using BERT** (Jonathan Fernandes, *from memory*). Hands-on step into modern transformer-based NLP.

## Suggested order

1. Machine Learning with Python: Foundations
2. NLP with Python for Machine Learning Essential Training
3. Karpathy's micrograd video (see [ML-basics.md](ML-basics.md)) for how neural nets work internally

LinkedIn Learning is mostly beginner to intermediate, so treat it as a quick on-ramp. For depth, pair it with Karpathy and fast.ai (its practical deep learning course also covers NLP and transformers).
